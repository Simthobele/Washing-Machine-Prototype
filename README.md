# Washing-Machine-Prototype
This project focuses on the design and development of a solar-powered washing machine prototype controlled by an Arduino microcontroller. The aim is to create a sustainable, energyefficient washing system that can operate in areas with limited access to electricity.

Background
Traditional washing machines consume a significant amount of electricity, which can be both costly and environmentally unsustainable. In rural and off-grid communities, where reliable power supply is limited, the challenge becomes even greater. With the increasing demand for renewable energy solutions, solar energy provides a viable alternative to power domestic appliances. To address this, the project applies embedded systems engineering by using an Arduino to control the washing machine operations, such as filling, washing, rinsing, and spinning. Simulation was first carried out on Tinkercad to validate the design using LEDs and sensors.This was followed by hardware implementation, which included an IR sensor for remote input, motor driver circuits, a water pump emulator, and a DC motor to simulate washing actions. By successfully integrating hardware and software components, the project not only highlights the potential of renewable-powered appliances but also showcases practical skills in embedded system design, simulation, and prototyping.
